# 割り勘計算

複数人の立替払いを1つの表で入力し、各人の収支と送金回数が最小になる精算方法を表示する Web アプリです（仕様: `split-bill-spec.md` v1.1）。
ログイン・サーバー・外部送信はありません。データはブラウザの localStorage に自動保存されます。

## 起動

Node.js 22.12 以上の 22.x、または 24.x が必要です（`package.json` の `engines`）。

```bash
npm install
npm run dev        # http://localhost:5173
```

本番ビルド（静的ファイルが `dist/` に出力され、Vercel などの静的ホスティングに配置できます）:

```bash
npm run build
npm run preview
```

## テスト

```bash
npm test           # Vitest（単体テスト + jsdom 上の UI 統合テスト）
npm run typecheck  # 型チェック
```

- `src/domain/expense.test.ts` — 入力検証、均等割り・固定・対象外、参加者の追加/削除、受入テスト No.1〜9, 15, 21
- `src/domain/settlement.test.ts` — 最小送金件数（総当たりとの一致）、全最小パターンの網羅と重複排除、No.12, 13
- `src/domain/rounding.test.ts` — 50円丸めの制約と選択順位（総当たりとの一致）、No.10, 11, 16〜20, 22〜24
- `src/App.test.tsx` — 画面操作（入力→集計→精算、固定、エラー、パターン循環、再読込での復元、コピー）

## 使い方

- 未入力の行で、支払った人の列に金額を入力すると、その人が支払者になり全員で均等割りされます。割り切れない場合は、支払者以外が切り上げ額を負担し、支払者が残りを負担します（例: 1,000円を3人 → 支払者 332円、他 334円ずつ）。端数で得をするのは支払者だけです。
- 負担額（赤字）のセルをクリックすると金額の変更（🔒固定）、固定解除、対象外（—）の設定ができます。
- 支払者のセル（太字）をクリックすると、支払額・支払者・自己負担額を編集できます。支払額を空欄/0にすると行が未入力に戻ります。
- 参加者名は既定で「参加者1」「参加者2」…。ヘッダーの名前欄はクリック / Tab で全選択され、Tab で隣の名前欄へ移動します。同じ名前（前後の空白・全角半角の違いを含む）は登録できません。
- 精算欄右上の「50円丸め」スイッチをONにすると、各人の最終収支だけを50円単位に調整します（1人あたり±49円以内、合計0円）。表の金額は変わりません。調整差額の内訳は折りたたみ表示です。

## 構成

```
src/domain/     計算ロジック（純粋関数・UI 非依存）
  allocate.ts     行内の負担額配分（均等割り・固定・対象外）
  expenseOps.ts   支出/参加者の編集操作（不正な更新は Result.error で拒否）
  balance.ts      支払総額・負担総額・収支
  rounding.ts     丸め（unit 引数。候補選択は閾値決定 → DP による辞書式最適化）
  settlement.ts   最小送金件数パターン探索（零和部分集合の最大分割 + 木の列挙）
  settle.ts       上記をまとめて画面用の精算結果を導出
src/storage.ts  localStorage 保存・検証・マイグレーション
src/state/      React 用の状態フック（失敗時は直前の状態を保持）
src/components/ 表・集計・精算・SVG 精算図
```

## 既知の制限

- 最小送金件数の厳密探索は、収支が0でない人が **14人以下** の場合に行います。それを超えると近似解（大きい送金人と受取人から順に対応）を表示し「最適保証なし」と明示します。
- 精算パターンは最大 **20件** まで表示します。それ以上ある場合は「表示は先頭20パターンまで」と表示します（最小件数の保証とは別管理）。
- 丸め単位は計算上 10円・100円なども扱えますが、UI には通常 / 50円丸めのみを表示しています（`SUPPORTED_ROUNDING_UNITS` に追加すると選択肢が増えます）。
- 「データ出力 / データ読込」（JSON ファイル）は簡易機能です（読み込み時はスキーマ検証を行い、現在のデータを置き換えます）。
- 保存データが破損している場合は、初期化を確認するまで上書き保存しません（破損データはファイルとして退避できます）。
- E2E テストは jsdom 上の React Testing Library で実施しています。実ブラウザでの自動 E2E（Playwright 等）は未導入です。
- 端数の配分ルールは仕様書 v1.1 の 6.1（余りを表示順に1円ずつ）から変更しています。支払者が「対象外」や「固定」の行、または支払額が非常に小さい行では、従来どおり表示順に配分します。
- 行・列の並べ替え、元に戻す（Undo）機能はありません。
- 参加者・行の削除ボタン（×）は Tab 移動の対象外です（名前欄間の Tab 移動を優先）。マウス / タップで操作してください。
